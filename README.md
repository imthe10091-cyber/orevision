## ⚠️ Disclaimer - Read Before Using on Any Server

This mod is built for **singleplayer worlds or servers you personally
administer**. If you join a server where you do **not** have staff/admin
permissions with this mod's ESP or X-ray enabled, here's what will
realistically happen:

- **You will very likely get banned.** Nearly every public Minecraft server's
  rules explicitly prohibit X-ray/ESP mods as cheating, regardless of intent.
  Server-side anti-cheat (e.g. NoCheatPlus, Vulcan, Grim, GrimAC, Polar,
  server-specific systems) actively looks for exactly this kind of behavior -
  players consistently mining straight to ore veins, digging toward
  unexposed blocks, or moving in ways that only make sense if they can see
  through terrain. Getting caught doesn't require the server "detecting the
  mod" itself; the *behavior* it enables is usually enough on its own.
- **Ban appeals citing "I was just testing a mod I built" rarely succeed.**
  Most server staff treat any client capable of X-ray/ESP the same
  regardless of your intent when you joined.
- **This can also violate the Minecraft EULA / Mojang's terms** in ways that
  put your Microsoft/Mojang account at risk on some servers, separate from
  any ban issued by the server itself.
- **This is not a multiplayer-safe mod.** Nothing here disguises network
  traffic or hides the mod's presence from a server; it's a plain client-side
  rendering mod, not an anti-detection tool, and was never designed to be one.

If you administer a server and want other trusted staff to use this, that's
a decision for you to make deliberately - not something to bring onto a
server (yours or anyone else's) by accident with it left toggled on.

**Reminder:** ESP and X-ray default to *off* on launch, but the `O`/`P`
keybinds toggle state that persists across play sessions - if you enable
either while testing in singleplayer and forget to turn it back off, it'll
still be on the next time you join any server, including ones where you
have no admin permissions.
